# Drones submission checklist

- [x] Official MDPI class bundle included and hashed.
- [x] Title, abstract, keywords, introduction, methods, results, discussion, conclusions.
- [x] Equations, exact decision algorithm, ablation, limitations, future work.
- [x] Main and supplementary figure sources in PDF/SVG/PNG plus CSV data.
- [x] References with DOI where available.
- [x] Author contribution, funding, ethics, data availability, acknowledgment, conflict declarations included as drafts.
- [ ] Replace anonymous author and affiliation metadata.
- [ ] Confirm all authors, funding, conflicts, and acknowledgments.
- [ ] Create clean public release and repository DOI.
- [ ] Re-check latest Drones instructions and LaTeX template immediately before submission.
- [ ] Obtain permission for any third-party content (none intentionally reused in generated figures).
- [ ] Preferably add target onboard hardware and clean 10-seed confirmation.
- [ ] Run final spell/style/reference audit after author edits.
