# Novelty and claim boundaries

| Claim | Evidence | Permitted wording | Prohibited wording |
|---|---|---|---|
| Global-to-local routing | Teacher/student code and ablation | Privileged graph teacher distilled into strict one-hop deployment policies | “First ever local UAV RL policy” |
| Risk-switched recovery | Source thresholds and scenario results | Interpretable switch combines normal and predictive local branches | “Provably optimal/safe routing” |
| Fused Exact | Source audit, forward-count regression, latency comparison | Removes duplicated branch evaluations while preserving deterministic exact semantics | “New smaller model” or “single neural branch” |
| External comparison | Common-simulator archive | Strongest reliability among eight implementations under the reported protocol | “Universally best” or direct superiority to original papers' reported numbers |
| A100 speedup | Same-session benchmark | 41.66% p95 reduction versus the legacy repeated CUDA path | “Real-time onboard A100 deployment” |
| CPU vs CUDA | Same-session device comparison + profiler | CPU is faster for this batch-one implementation/session | “CPUs are always faster than GPUs” |
| Fast variant | Five-seed gate | 65.65% faster CUDA p95 but fails reliability gate | “Equivalent to Exact” |
| Early Exit | Full replay and A100 timing | Zero observed mismatch in current evaluation but 9.42% slower | “Formally equivalent” |
