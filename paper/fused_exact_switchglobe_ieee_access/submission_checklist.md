# IEEE Access submission checklist

## Format and structure

- [x] Official IEEE Access LaTeX class and support assets included.
- [x] Double-column, single-spaced manuscript structure.
- [x] Abstract is 150–250 words and contains no references or displayed equations.
- [x] Seven index terms are provided (official range: 3–10).
- [x] Introduction, related work, system model, method, experimental protocol, results, ablation, limitations, future work, and conclusion are present.
- [x] Equations and exact inference algorithm are included.
- [x] IEEE-style numbered citations and `IEEEtran.bst` are used.
- [x] Author-contribution, funding, data-availability, conflict-of-interest, acknowledgment, and AI-assistance disclosures are included as drafts.
- [x] Biography placeholder is included; add one biography for every author.

## Figures, tables, and evidence

- [x] Five main figures are available in vector and raster formats.
- [x] Twenty supplementary figures are available in PNG/SVG with CSV sources.
- [x] A100 confirmatory benchmarks and operator-profile tables are included.
- [x] Statistical aggregation, effect sizes, uncertainty, and ablation evidence are documented.
- [x] Literature comparison and novelty-claim matrices are included.
- [x] No third-party figure is intentionally reproduced.

## Required author actions

- [ ] Replace anonymous author, affiliation, correspondence, and biography placeholders.
- [ ] Add ORCID iDs for all authors in the submission system and source where appropriate.
- [ ] Confirm author order and obtain approval from every author.
- [ ] Verify author contributions, funding, conflicts, and acknowledgments.
- [ ] Create a clean public code/data release and persistent repository DOI.
- [ ] Confirm whether the supplementary PDF should be uploaded separately or merged according to the submission portal.
- [x] Verify that both the source archive and manuscript PDF are below the portal’s 40 MB limit.
- [ ] Preferably add target onboard-hardware measurements and a clean 10-seed confirmation.
- [ ] Re-check the current IEEE Access instructions and template immediately before upload.
- [ ] Run the final language, reference, and metadata audit after author edits.

## Length note

IEEE Access strongly recommends keeping the submitted article below 20 pages. If author edits push the manuscript above that level, move secondary diagnostics to the supplement or contact the journal before submission.
