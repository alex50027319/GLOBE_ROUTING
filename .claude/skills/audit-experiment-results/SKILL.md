# Audit Experiment Results

1. Ground phase, config, mode, seeds, scenarios, methods, and episode count.
2. Validate expected versus observed row cardinality.
3. Check duplicate rows, missing cells, failure reasons, and inconsistent metric definitions.
4. Compare PDR with delay p95, deadline, energy, input bytes, and drop rate.
5. Separate direct evidence from interpretation.
6. Produce the `templates/result-audit.md` structure with file paths for every important claim.
