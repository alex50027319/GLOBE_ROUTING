# Build Professor Deck

1. Identify the audience, presentation duration, source Markdown, and result artifact.
2. Organize the story as problem, environment, methods, episode flow, hard scenarios, results, limitations.
3. Use topology and packet-flow visuals for structural hole and predictive break.
4. Keep terminology consistent with code and define English scenario names in Korean.
5. Render every slide and inspect clipping, overlap, tiny text, and figure readability.
6. Put detailed assumptions and likely questions in speaker notes.
