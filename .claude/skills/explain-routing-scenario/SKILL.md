# Explain Routing Scenario

Read the scenario builder and campaign registration before quoting parameters.

Cover only what the question needs, but preserve these distinctions:

- scenario versus method versus episode;
- random endpoints versus fixed structural-hole/predictive-break endpoints;
- current link quality versus predicted link lifetime;
- local observation versus privileged global Teacher observation;
- normal Geo-Residual branch versus Predictive branch and switching condition;
- simulator unit/proxy versus physical meter, Joule, Mbps, and control overhead.

For a step-by-step explanation, follow one packet through candidate mask, risk features, policy
action, environment transition, and delivery/drop outcome.
