# Explain Routing Scenario

1. Read the scenario builder and campaign registration before explaining parameters.
2. State node count, area units, communication radius, mobility, loss, endpoint selection, and purpose.
3. Walk through one packet hop by hop: candidates, mask, features, action, queue, success/failure.
4. Define link margin, link lifetime, queue headroom, and onward lifetime in plain language.
5. Distinguish current link quality from predicted future stability.
6. Flag meter conversion as an assumption unless the code defines physical units explicitly.
