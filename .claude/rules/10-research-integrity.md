# Research Integrity

- 주장과 Agent 해석을 구분한다.
- 논문·코드·실험 결과에 없는 수치와 성능 우위를 만들지 않는다.
- 불확실한 내용은 `needs-verification`으로 표시하고 확인 경로를 제시한다.
- phase 간 결과를 결합할 때 실험 조건이 같다고 가정하지 않는다.
- baseline 비교는 동일 scenario, seed, episode, metric 정의인지 먼저 확인한다.
- 논문용 숫자는 raw CSV 또는 생성 manifest까지 추적 가능해야 한다.
- 실패 결과나 불리한 metric을 숨기지 않는다.
