# Research Documentation

- 공개 이름은 SwitchGLOBE, Phase 번호는 역사적 계보로 표현한다.
- `method_history.md`, `paper_method_summary.md`, `simulation_protocol.md`의 역할을 섞지 않는다.
- 코드 default와 문서 명령이 다르면 코드와 의도된 공개 workflow를 함께 확인한다.
- metric 단위와 구현 한계를 생략하지 않는다.
- 외부 논문 주장과 이 프로젝트의 adaptation 평가를 분리한다.
