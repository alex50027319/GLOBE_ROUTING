# Paper Rules

- 구현된 기법, 실험된 기법, 향후 계획을 서로 구분한다.
- 성능 수치는 표·그림의 실제 생성 원본과 대조한다.
- 외부 baseline 인용은 원 논문의 조건과 본 실험의 재구현 조건을 구분한다.
- novelty는 기존 연구와의 차이를 구성요소 나열이 아니라 문제·정보·학습·실행 관점에서 설명한다.
- LaTeX 편집 후 compile하고 경고와 깨진 reference를 확인한다.
- 생성 PDF나 figure를 기존 최종본 위에 무심코 덮어쓰지 않는다.
