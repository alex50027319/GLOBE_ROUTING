# Presentation Rules

- 한 슬라이드에는 하나의 주장과 이를 뒷받침하는 근거를 둔다.
- scenario, method, episode를 먼저 설명한 뒤 결과를 해석한다.
- structural hole과 predictive break는 topology 그림과 시간 흐름으로 설명한다.
- PDR, p95 delay, overhead를 같은 단위처럼 시각화하지 않는다.
- 작은 글씨, 잘린 표, 겹친 도형이 없는지 렌더링 결과로 확인한다.
- 발표용 단순화가 코드 사실을 바꾸지 않게 speaker note에 가정을 기록한다.
