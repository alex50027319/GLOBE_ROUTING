# Ad Hoc Networks Overleaf Draft

This directory is an Overleaf-ready, free-format Elsevier draft for a proposed submission to *Ad Hoc Networks*.

## Official links

- Journal: <https://www.sciencedirect.com/journal/ad-hoc-networks>
- Aims and scope: <https://www.sciencedirect.com/journal/ad-hoc-networks/about/aims-and-scope>
- Guide for authors: <https://www.sciencedirect.com/journal/ad-hoc-networks/publish/guide-for-authors>
- Elsevier LaTeX instructions: <https://www.elsevier.com/en-gb/researcher/author/policies-and-guidelines/latex-instructions>
- Elsevier generative-AI policy: <https://www.elsevier.com/about/policies-and-standards/generative-ai-policies-for-journals>

The journal accepts free-format initial submissions, but the official guide must be checked again immediately before submission. This draft uses the standard Elsevier `elsarticle` class and numbered bibliography style.

## Upload to Overleaf

1. Use the generated `ad_hoc_networks_overleaf_ready.zip` file.
2. In Overleaf, select **New Project → Upload Project**.
3. Upload the ZIP.
4. Set the main document to `main.tex` if Overleaf does not detect it automatically.
5. Select pdfLaTeX as the compiler.
6. Run **Recompile from scratch**.

## Files

- `main.tex`: manuscript draft with explicit TODO gates
- `references.bib`: starter bibliography from the Notion competitor database
- `highlights.txt`: separate highlights upload
- `cover_letter.md`: cover-letter draft
- `submission_checklist.md`: scientific and formatting gate
- `figures/`: place final figure files here
