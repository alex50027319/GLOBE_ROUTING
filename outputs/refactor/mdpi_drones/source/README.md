# Fused Exact SwitchGLOBE paper package

Primary target: MDPI **Drones** (Article). This is a complete research draft, not a claim that the manuscript is submission-ready without author metadata and the major-review items.

## Files

- `main.tex`: English journal manuscript.
- `supplementary.tex`: complete 20-figure analysis, detailed provenance, statistics, and reproduction checklist.
- `cover_letter.tex`: journal cover-letter draft.
- `references.bib`: cited literature.
- `figures/`: five publication figures generated for this paper in PDF/SVG/PNG.
- `supplementary_figures/`: 20 verified analysis figures in PNG/SVG.
- `figure_data/`: one CSV per figure.
- `tables/`: copied authoritative summary and profiling tables.
- `literature_comparison.csv`: 45 accessible records from the project Notion database.
- evidence, novelty, metric, statistical, review, and submission markdown files: audit trail.

## Interpretation

The final proposal is **Fused Exact SwitchGLOBE**. It evaluates each original branch once and reuses the same intermediate logits for action and diagnostics. FastSwitchGLOBE remains an approximate speed/quality candidate because it fails the predefined reliability gate. Early Exit is a documented negative result.
