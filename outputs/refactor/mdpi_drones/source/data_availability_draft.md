# Data availability statement — draft

The manuscript is accompanied by source code, configuration files, raw episode archives, seed summaries, paired-effect tables, A100 benchmark manifests, operator profiles, figure-source CSV files, and SHA-256 records in the project repository. Before submission, the authors will create a clean, immutable public release and insert its repository URL and DOI here. If any checkpoint or third-party artifact cannot be shared, the restriction, license, and access procedure must be stated explicitly rather than described as “available on request” without a process.
