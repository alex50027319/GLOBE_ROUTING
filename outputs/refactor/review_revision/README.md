- `ieee_access/DiSwitch_IEEEAccess_Reviewed.pdf`: IEEE Access 개정 원고, 17쪽.
- `ieee_access/DiSwitch_IEEEAccess_Overleaf.zip`: main.tex가 루트에 있는 Overleaf 프로젝트.
- `mdpi_drones/DiSwitch_MDPI_Drones_Reviewed.pdf`: MDPI Drones 개정 원고, 21쪽.
- `mdpi_drones/DiSwitch_MDPI_Drones_Overleaf.zip`: main.tex가 루트에 있는 Overleaf 프로젝트.

- `BUILD_CHECKS.md`, `SHA256SUMS.txt`: 컴파일/소스 참조 및 파일 무결성 기록.

빨간 글씨와 빨간 테두리는 삭제 또는 보충자료 이동 후보입니다. 파란 글씨는 저자 확인·보완이 필요한 내용입니다. 실험 수치는 기존 아티팩트에서 유지했으며 이번 작업은 새 실험을 포함하지 않습니다.

각 소스의 `REVISION_FIGURE_INDEX.md`에서 그림 호출 위치를 확인할 수 있습니다. `main.tex`는 두 저널에서 같은 과학적 수정사항을 반영했습니다. source에 포함된 이전 audit 문서는 역사적 기록이며 최신 판단은 `REVIEWER_REPORT_KO.md`를 우선합니다. 동반 supplementary는 이전 데이터 스냅샷의 소스이며 그 상태는 `SUPPLEMENT_STATUS.md`에 명시되어 있습니다. 이번 최종 검증 PDF는 두 main.tex입니다.

Overleaf 설정: Main document = `main.tex`, compiler = pdfLaTeX. 이 파일들은 심사 대응 편집본이므로 저자 확인 항목을 채우고 삭제 후보의 최종 배치를 결정한 뒤 제출본을 만드세요.
